# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, send a report to the project maintainers directly via GitHub's [private vulnerability reporting](https://github.com/sud-s/workspace-task-manager/security/advisories) feature.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

Please include:
- Type of vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We appreciate responsible disclosure and will credit you when the fix is published.
